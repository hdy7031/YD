# YD · Your Day V0.2.17

本地日程中枢：Windows 本地课表、日程、待办与准备提醒。使用 Electron、TypeScript、React、SQLite（sql.js）。
品牌与设计规范见 `brand/README.md`。

## 当前交付状态

0.2.17 品牌重构：产品统一为 YD / Your Day，重做 logo 与图标资产、配色 token、侧栏品牌区、标题栏、卡片与空状态质感；业务能力与 0.2.16 保持一致。实现范围、测试及已知限制见 `ACCEPTANCE-V0217.md`，扩展边界见 `TRANSACTION-HUB.md`。

本轮验证使用独立测试数据库和历史备份，不覆盖安装当前正式应用、不修改正式用户数据。

## 构建

开发环境需要 Windows x64、Node.js 24 或更新版本，以及允许访问 npm 和 Electron 发布下载地址的网络。应用安装后的使用不需要 Node.js。

解压后运行 `build-windows.cmd`，依次安装依赖、类型检查、运行测试并生成安装包。任一步失败都会停止，不能当作成功交付。

也可以在源码目录执行：

```text
npm install
npm run typecheck
npm test
npm run build
npm run start
npm run dist
```

安装包默认输出位置：`release/YD-Setup-0.2.17.exe`。安装范围为当前 Windows 用户，保留卸载后的用户数据。未配置发行者签名证书。0.2.17 的显示名与图标改为 YD，但数据目录仍固定使用当前 Windows 用户的 `%APPDATA%\事务助手\dayhub.sqlite`（改名不影响数据），并在每次读取和修改前从 SQLite 重新同步持久状态。


Electron 固定为 44.2.0（[官方发布记录](https://releases.electronjs.org/)）；其余依赖版本由 `package-lock.json` 锁定，后续构建优先使用 `npm ci`。

## 使用

1. 首次打开，分别核对“我”和“Ta”的学期起始周、教学周数和每节起止时间。预置作息是编辑模板，不代表实际学校作息。
2. 课表管理以七天横栏和节次纵栏显示；切换教学周即可查看前后半学期差异。点击课程色块编辑、复制或删除，点击空白格可按对应星期和节次新增；也可载入 `.dayhub-schedule.json` 文件。
3. 在“我的安排”或“TA 的安排”选择日期；当天以同结构的日程摘要 + 时间带 + 事项列表展示，课程卡片可修改仅该次调课／停课。在课表管理中可恢复原课程。
4. “新建待办”和“新建会议”只在“我的安排”提供。“事项与会议”统一搜索、筛选和管理两类记录；无截止时间的待办也会保留。
5. 从 QQ 复制通知文字到“文字通知”，或通过导入图片、粘贴截图保存原图。点击本机识别后核对文字；识别失败时继续看图录入。保存通知后可转待办或录入为课程。你也可以把课表图片交给 Codex 整理成课表文件，再在课表管理页核对人数、学期和课程数后载入。
6. 桌宠常驻显示双方基于已录入安排的状态。切换到悬浮球后，左侧 Y 和右侧 D 作为低调的 monogram 身份标记；默认没有“我／Ta”或状态文字。鼠尾草绿、琥珀、橘、雾蓝、暗红和灰色状态点依次表示空闲、即将开始、忙碌、专注、冲突和离线；悬停某一侧才显示状态词。
7. 未处理提醒中可确认或延后 10 分钟。确认提醒不会自动完成待办；标记待办完成则取消后续提醒。
8. 在设置中测试系统通知，并定期导出完整备份。

## 数据与提醒

- 数据位于 Electron 当前用户的应用数据目录（安装版为 `%APPDATA%/事务助手`），开发和安装版应在验收时确认实际目录。`dayhub.sqlite` 为 SQLite 文件，`attachments` 保存以内容哈希命名的原图。
- 从 Microsoft Store/Windows 包应用内启动开发命令时，Windows 可能把 `%APPDATA%` 重定向到该包的 `LocalCache\Roaming`。不得在这种环境中导入或核对用户的正式数据；正式数据必须通过用户桌面启动的安装版日志或沙箱外探针验证。测试和界面审计一律使用项目内的 `test-data`。
- 所有变更在主进程串行提交；先原子落盘，再返回成功。`.bak` 保存上一份数据库副本，损坏主文件会另存后再恢复。
- 完整 `.dayhub` 备份包含状态与关联图片；恢复前自动保存完整备份到应用数据目录中的 `backups` 文件夹。
- 图片在本机读取，不调用云端识别。首版没有模型 API、网络同步或 QQ 登录。
- 默认北京时间。课程提前 10 分钟，会议提前 30 分钟；待办默认提前 24 小时、2 小时和到期提醒。Ta 的课程提前 5 分钟、开始与结束时显示气泡；教研单独标识。气泡默认 8 秒收起，停留可暂停；关闭气泡不会完成待办或处理系统提醒。
- 保存时已经过去的提前提醒不补发。应用恢复后汇总此前错过的提醒，不连续弹出。
- Windows 可能因系统通知设置或勿扰模式而隐藏提醒；“已提交系统通知”不表示已送达或已阅读。未处理列表仍然保留。

## OCR 说明

OCR 使用 `native/ocr.ps1` 调用 Windows.Media.Ocr，需要简体中文识别语言和允许执行该辅助脚本的系统配置。脚本通过参数接收路径，不执行通知内容。打包时辅助脚本位于 app.asar 外，以便系统读取。

此设备已检测到简体中文 OCR 语言，但执行脚本被 Windows 策略阻止。应用不会关闭或绕过该策略。正式验收前，需要在允许执行该脚本的环境验证，或将辅助实现替换为经验证的原生 OCR 宿主；在这之前，人工录入可以使用。

## 首版限制

- 电脑关机、休眠或应用退出期间不触发提醒；恢复后汇总。
- 图片只提取文字，不自动还原表格。支持 PNG/JPEG、20 MB 以内、2400 万像素以内；OCR 还受 Windows 支持的图片尺寸限制，超限需裁剪。
- 准备清单目前保存于事项记录；同一重复课程的勾选状态按课程共享，下次课前需要手动重置，尚未实现逐次课程清单。
- Ta 有课表时直接显示“上课中 / 当前无课 / 今日课程已结束 / 今天无课”等已确认的计划状态；停课和调课按最终课程实例展示。
- 已有临时调课时，如果修改课程的星期、周次或学期使该临时记录不再有效，需要先恢复／移除对应临时记录。
- 任务时间、资格、准备要求都需要人工核对。“决定参加”只创建待办，不执行报名。
- 安装版的真实课表、OCR 与系统通知送达仍按 `ACCEPTANCE.md` 验收；自动化测试不能替代一周日常使用。

## 代码组织

- `src/core.ts`：日期、课表、临时变更、待办和提醒状态机；不依赖界面与 Electron。
- `src/store.ts`、`src/backup.ts`：串行 SQLite 保存、失败回滚、恢复与附件校验。
- `src/main.ts`、`src/preload.cjs`：窗口、托盘、受限进程接口、本地图片与系统通知。
- `src/ui`：React 界面；`native`：OCR 辅助实现；`tests`：核心、数据库、显示态与窗口位置计算测试。验收脚本哪些是当前发布门禁、哪些只是历史脚本，见 `docs/verification-v030.md`。
- `src/companion-display.ts`、`src/companion-frame.ts`、`src/companion-assets.ts`、`src/ui/companion-custom.ts`：桌宠显示态投影、素材契约、主进程素材解析与专属角色渲染层。

测试存储使用 Node 自带的真实 SQLite 引擎适配 Store 接口，覆盖文件写入行为；这不替代发布时对 sql.js WASM 加载的测试。测试数据位于独立临时目录，不使用真实日程。

## V0.2 使用补充

- 主进程每秒读取 Windows 系统时间，所有窗口共享同一份北京时间状态。没有联网校准；系统时间错误时应先纠正 Windows 时间。
- 我的安排 2026-09-14 开始、16 周；TA 的安排 2026-09-07 生效、20 周暂定（同行者按档案显示名称，默认回退为「TA」）。可在学校作息中取消“暂定”或调整周数。
- 教研与授课分开；状态只表示事务助手内已录入的当前计划，不声称实时监控现实世界。
- 升级第一次启动会在应用数据目录 backups 中保存 before-v02 完整备份。既有课程、待办和提醒保留。
- 0.2.20 起桌宠只有一个默认形象：专属角色桌宠。十张状态素材由 `artwork/companion/custom/` 原图经 `npm run assets:companion` 规范化生成（5 列 × 2 行十宫格或旧 3 × 2 合集 + 单图状态），随双方状态与本机时间切换，桌宠底部用 D / Y 状态条低调表达忙闲；设置里只保留“专属角色桌宠 / 玻璃悬浮球”两种显示方式，缺帧时回退到相近动作或同一形象的待机帧。
- 0.2.16 起桌宠使用固定画布：窗口尺寸只由显示模式与大小决定，拖动期间冻结全部角色动画，只移动窗口本身；底部状态条独立成层，不会因为角色动作或拖动而消失。
- 0.2.16 起通知收件箱只有一个录入入口：直接 `Ctrl+V` 粘贴文字或截图，也可以把图片拖进输入区；原文先保存，`Ctrl+Enter` 或缺省主操作「整理通知」立即整理并在右侧打开结果。
- 悬浮球完全由 HTML/CSS 绘制，能随 Windows DPI 保持锐利；桌宠全部使用透明 PNG，由浏览器等比缩放，不开 pixelated。
- 专属形象的网页端生图步骤与完整提示词见 `DESKPET_IMAGE_PROMPT.md`。
- 本次窗口/交互报告位于 `test-data/v02-runtime-1788891963650`，最终截图位于 `test-data/v027-final`；硬件多屏拔插、系统勿扰投递、真实休眠及一周使用仍需实机持续核对。

如果 Electron 运行时或 `winCodeSign` 下载失败，可使用已安装的同版本运行时与 npmmirror 二进制镜像打包：

```text
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npx electron-builder --win nsis --x64 --config.electronDist=node_modules/electron/dist
```

0.2.14 安装包按此方式生成：`release/DayHub-Setup-0.2.14.exe`。
