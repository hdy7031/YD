# DECISIONS

Migrated rationale from the prior AGENTS, 2026-10-06; original decision dates are not known. No new release or design approval is implied.

## YD priority over the generic software default
Retain stability, data correctness, domain clarity, maintainability and coherent experience in that order. A real user outcome must protect local data and predictable state; a quick demo or the generic Software Profile priority cannot override that project stance.

## Local data and accountable inference
Schedules/status remain locally usable and manual facts authoritative. External messages and model results are advisory, source-preserving and reviewable before consequential records are confirmed. Unofficial integration reliability cannot be asserted without evidence.

## Quiet presentation with preserved truth
Summary/detail separation keeps daily cards and the companion scannable without deleting provenance. Missing optional fields need no repeated placeholders. Visual hierarchy follows the task, and copy/layout cleanup must preserve domain truth. Choice controls use a consistent restrained language because settings should support decisions without extra explanation.

## Presentation scope
Prior AGENTS established information-density discipline to guide requested presentation fixes, not authorize unsolicited redesign. Apply it within the current baseline restrictions in PROJECT_CONTEXT. When the user requests verbosity/crowding cleanup, converge obvious issues in the same page/component family; do not expand into a global redesign or copy rewrite.

## Accepted baseline versus lasting design direction
The prior AGENTS treated Mist & Sage and current assets/layout as an accepted stage baseline. Its freeze prevents incidental redesign; that temporary restriction is recorded in PROJECT_CONTEXT, separate from lasting readability, low interruption and truthful presentation principles. This reconciliation does not lift the freeze.
